### 👨‍💻 About Me

I'm a Computer Science student and **Junior Laravel Backend Developer** who enjoys building clean, efficient, and maintainable web applications.

- 🎓 **Education**: B.Sc. in Computer Science (in progress), Faculty of Computers and Information, Tanta University (since 2023)
- 💼 **Experience**: PHP Web Developer at Createivo Company, Mansoura (Feb – Apr 2025)
- 📚 **Training**: Web Development Using PHP & Generative AI — Information Technology Institute (ITI), Aug – Sep 2026
- 💻 **Core Focus**: PHP & Laravel backend development, RESTful API design & relational database modeling
- ⚙️ **Best Practices**: OOP, MVC structure, RBAC authorization & Eloquent ORM
- 📍 **Location**: Tanta, Egypt | Open to Junior Backend roles, internships & collaborations

---

### 🚀 What I Do

- 🔹 **Build Laravel Web Applications** — MVC architecture, Blade templating & Livewire interfaces.
- 🔹 **Develop RESTful APIs** — JSON endpoints, token authentication with Laravel Sanctum & Postman testing.
- 🔹 **Database Design & Management** — Relational MySQL schemas and Eloquent ORM relationships.
- 🔹 **Authentication & Authorization** — Role-Based Access Control (RBAC) for users, roles & permissions.
- 🔹 **API & AI Integration** — Integrating third-party services, including the Google Gemini API.
